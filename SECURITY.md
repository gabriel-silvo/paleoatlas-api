# Segurança

A API atual oferece somente leitura. Segredos e tarefas administrativas pertencem ao ambiente de manutenção, fora do contrato público.

Para relatar uma vulnerabilidade, use a funcionalidade de relato privado de segurança do GitHub quando habilitada. Se ela não estiver disponível, abra uma issue solicitando um canal privado, sem publicar credenciais, dados pessoais ou detalhes de exploração.

Inclua versão/commit, recurso afetado, impacto e passos mínimos de reprodução no relato privado. Para correções de taxonomia ou referências, use as instruções de contribuição.
