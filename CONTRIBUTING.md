# Contribuir

Para iniciar, siga o README. Execute `npm run check` antes de abrir uma alteração. A CI também executa o teste de PostgreSQL; localmente ele exige `DATABASE_URL`, migração e carga.

Correções científicas devem informar ID ou nome do táxon, campo afetado, afirmação proposta e referência primária verificável. Diferencie erro de transcrição, revisão taxonômica e hipótese alternativa. Discussões legítimas podem coexistir; a posição da PBDB não precisa ser apresentada como consenso.

Para mudar importação ou publicar dados, siga [a política de dados](docs/DATA_POLICY.md). Inclua evidências, relatório, snapshot e testes correspondentes. Não edite apenas o JSON normalizado: ele é reconstruído a partir das evidências. A primeira versão ainda não tem armazenamento de sobreposições curatoriais.

Propostas de imagens precisam de origem, autoria, licença e exigência de atribuição. Conteúdo de acesso público não é automaticamente reutilizável.
